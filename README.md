# C 语言圣经

> 用 C 讲 C。只讨论语法与语言特性。

这是一套“自解释”的 C 语言教材：每一章都是一个可以编译、运行、修改、破坏的程序。源码是课文，Markdown 是路标，编译器是裁判。

**当前进度：第 0–11 章已完成，覆盖 ISO C17 的核心语言，并附一个综合练习和一份 C11/C17 补遗 / C23 速览。**

## 为什么叫“圣经”？

这里的“圣经”不是宗教文本，也不是说它是唯一正确的 C 教材。这里的“经”取的是“正经”的意思：一套关于 C 语言本身的、尽量回到标准与第一性原理的读本。

本教材只回答这类问题：

- 一个声明到底声明了什么？
- 一个表达式何时、以何种顺序求值？
- 一个对象从哪里开始，到哪里结束？
- 编译器凭什么接受或拒绝一行代码？

它不教你写 GUI，不教你用框架，也不把“常见写法”冒充“语言规则”。遇到标准与实现不一致的地方，会明确区分。

## 这套教材适合谁

- 已经会用至少一门编程语言，但想系统补齐 C 语法的人；
- 写过 C，却对指针、对象模型、链接、未定义行为似懂非懂的人；
- 想从“能跑”走向“知道标准保证了什么”的人。

它不适合完全没写过代码的人，也不是标准库 API 手册。标准库只在必要的地方出现，例如 `printf`、`memcpy`、`strlen`。

## 阅读方法

每章按同一个节奏展开：

1. **读**：先看这一章引入的语法。
2. **跑**：编译并运行完整程序。
3. **拆**：逐行解剖，知道每个字符为什么在那里。
4. **坏**：故意删掉一个分号、改错一个名字，读编译器给的诊断。
5. **练**：做练习，把知识变成手上的动作。

不要只读不跑。C 的很多规则，只有在你把代码改坏、看编译器如何反应之后，才会真正变成直觉。

## 开始

要求：一个支持 C17 的编译器（GCC、Clang 或 MSVC），以及一个终端。源文件使用 UTF-8 编码；MSVC 用户请加 `/utf-8`，否则中文注释可能被按本地代码页解释。

```sh
make          # 构建全部章节
make check    # 用 -Werror 重新构建全部章节
make run      # 构建并依次运行全部示例
```

`make run` 的输出会比较长；想只看某一章，可以直接构建对应目标：

```sh
make 05-arrays-pointers/arrays
./05-arrays-pointers/arrays
```

也可以进入章节目录直接编译：

```sh
cd 00-hello-world
cc -std=c17 -Wall -Wextra -Wpedantic hello.c -o hello
./hello
```

看到下面这行，就说明工具链和教材都正常：

```text
Hello, World!
```

## 约定

- 以 **ISO C17** 为基线；涉及 C23 的地方会单独标注。
- 示例尽量只依赖标准 C 和宿主环境的最小假设。
- 代码风格是 K&R 的变体：4 空格缩进，左花括号不换行。
- “实现定义”“未指定”“未定义行为”是三个不同的词，教材会严格使用。
- 每章的 `.c` 文件都可以单独编译；第 8 章的多文件程序在根 `Makefile` 里显式链接。

## 验证

本仓库在 GCC 10（C17）下用以下配置验证过：

```sh
make check
```

它会对所有单文件程序使用：

```text
-std=c17 -Wall -Wextra -Wpedantic -Werror
```

第 8 章的多文件程序单独链接；第 10 章的 `portable.c` 还额外用 AddressSanitizer + UndefinedBehaviorSanitizer 运行过。

## 范围

这套教材覆盖 C17 的核心语言：

- 对象、类型、声明、初始化、转换；
- 运算符、表达式、求值顺序；
- 控制流、函数、递归、作用域；
- 数组、指针、字符串、聚合类型；
- 存储期、链接、多文件程序；
- 预处理器；
- 未定义行为、实现定义、未指定行为与可移植性。

附录补充了 `_Alignas`、VLA、变参函数、复数、原子/线程存储等 C11/C17 特性，并给出 C23 的速览。

它不展开标准库 API 大全、POSIX、操作系统接口、GUI、构建系统和 C23 的全部细节。教材的目标是让你读懂语言本身，而不是背完所有库函数。
