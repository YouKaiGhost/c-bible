# C 语言圣经

> 用 C 讲 C。只讨论语法与语言特性。

这是一套“自解释”的 C 语言教材：每一章都是一个可以编译、运行、修改、破坏的程序。源码是课文，Markdown 是路标，编译器是裁判。

## 为什么叫“圣经”？

这里的“圣经”不是宗教文本，也不是说它是唯一正确的 C 教材。这里的“经”取的是“正经”的意思：一套关于 C 语言本身的、尽量回到标准与第一性原理的读本。

本教材只回答这类问题：

- 一个声明到底声明了什么？
- 一个表达式何时、以何种顺序求值？
- 一个对象从哪里开始，到哪里结束？
- 编译器凭什么接受或拒绝一行代码？

它不教你写 GUI，不教你用框架，也不把“常见写法”冒充“语言规则”。遇到标准与实现不一致的地方，会明确区分。

## 阅读方法

每章按同一个节奏展开：

1. **读**：先看这一章引入的语法。
2. **跑**：编译并运行完整程序。
3. **拆**：逐行解剖，知道每个字符为什么在那里。
4. **坏**：故意删掉一个分号、改错一个名字，读编译器给的诊断。
5. **练**：做练习，把知识变成手上的动作。

## 开始

要求：一个支持 C17 的编译器（GCC、Clang 或 MSVC），以及一个终端。源文件使用 UTF-8 编码；MSVC 用户请加 `/utf-8`，否则中文注释可能被按本地代码页解释。

```sh
make          # 构建第 0 章
make run      # 构建并运行
```

也可以直接编译：

```sh
cc -std=c17 -Wall -Wextra -Wpedantic 00-hello-world/hello.c -o 00-hello-world/hello
./00-hello-world/hello
```

看到下面这行，就说明工具链和教材都正常：

```text
Hello, World!
```

## 约定

- 以 **ISO C17** 为基线；涉及 C23 的地方会单独标注。
- 示例尽量只依赖标准 C 和宿主环境的最小假设。
- 代码风格是 K&R 的变体：4 空格缩进，左花括号不换行。
- “实现定义”“未指定”“未定义行为”是三个不同的词，教材会严格使用。
